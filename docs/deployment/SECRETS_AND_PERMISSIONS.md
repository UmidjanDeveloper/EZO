# Secrets, permissions and AI provider controls

This file lists placeholder names only. **No secret value exists in this repository.** The
unit test `test_env_examples_contain_no_secret_values` enforces that for every
`deploy/**/*.env.example`.

## Secret inventory

Each secret is a server-only `SecretStr` setting (`apps/api/src/ezo_api/settings.py`) or a
host secret.

| Name | Used by | Where it lives | Generated by | Rotation |
|---|---|---|---|---|
| `EZO_API_TOKEN` (≥32 characters) | API owner auth | `deploy/primary/secrets/compose.env` (mode 600) or the host's dashboard secret | `bootstrap-secrets.sh` (`token_urlsafe(48)`) | Every 90 days, or immediately on suspicion: replace, restart the API, re-enter it in the browser |
| `EZO_DB_ADMIN_PASSWORD` | PostgreSQL superuser (container-local administration only) | `secrets/compose.env` | `bootstrap-secrets.sh` | `ALTER ROLE postgres PASSWORD …` through `docker exec` |
| `EZO_DB_APP_PASSWORD` | The `ezo_app` role (API and workers) | `secrets/compose.env` | `bootstrap-secrets.sh` | `ALTER ROLE ezo_app PASSWORD …`, update the env, restart |
| Database TLS CA key (`secrets/db-tls/ca.key`) | Issues the `db` server certificate | Host, then **moved offline** after issuing | `bootstrap-secrets.sh` | Reissue the server certificate before day 825 |
| `OPENAI_API_KEY`, `GEMINI_API_KEY`, `ANTHROPIC_API_KEY` | Model adapters | `primary.env` (mode 600) | Provider console, by the owner | Provider-side; restrict each key to EZO's server IP where the provider allows it |
| `ELEVENLABS_API_KEY`, `VOICESTUDIO_API_KEY` | Voice | `primary.env` | Owner | As above |
| `TAVILY_API_KEY`, `EZO_GITHUB_TOKEN` | Web search; GitHub learning (read-only, fine-grained) | `primary.env` | Owner | As above |
| `EZO_SUPABASE_STORAGE_KEY` | Free-beta Storage only | Render dashboard secret (`sync: false`) | Supabase dashboard (server secret key) | Supabase key rotation |
| R2 Object Read & Write token (bucket-scoped) | `backup.sh` through rclone | rclone config on the host (mode 600) | Cloudflare dashboard | Yearly |
| age **private** key | Backup decryption | **Offline, with the owner only** | `age-keygen` on the owner's machine | Never on a server |

**Rules:**
- Never put these in Git, Next.js `NEXT_PUBLIC_*` variables, URLs, screenshots or chat.
- Production logs redact every `SecretStr` and the database password (`ProductionFormatter`).
- `deploy/primary/.gitignore` excludes `secrets/` and `primary.env`.

## Least-privilege permissions

- **Database:** `ezo_app` is NOSUPERUSER, NOCREATEDB, NOCREATEROLE, NOBYPASSRLS, with a
  connection limit.
  - `pg_hba` allows it **only** over `hostssl` with scram-sha-256.
  - Startup refuses any privileged role. Verified locally on PG16 and on Supabase PG17.
- **Network:**
  - only Caddy publishes ports (80/443);
  - the database sits on an `internal: true` network;
  - the executor reaches PostgreSQL only over WireGuard (future).
- **Containers:** read-only root, `cap_drop: ALL`, `no-new-privileges`, and memory and PID
  limits on every EZO service.
- **Connectors:** read-only scopes are sufficient for inspection. The only extra grant needed
  is Vercel team scope, and only for reading projects and domains.

## AI providers and voice — budget controls

Existing per-process controls are set in `primary.env.example`. Counters reset when the
process restarts.

| Control | Variable | Default in template |
|---|---|---|
| Model calls per day (process) | `EZO_PROVIDER_CALLS_PER_DAY` | 200 |
| Concurrency, operation deadline | `EZO_PROVIDER_CONCURRENCY`, `EZO_PROVIDER_OPERATION_SECONDS` | 1, 180 s |
| Output tokens, input characters | `EZO_PROVIDER_MAX_OUTPUT_TOKENS`, `EZO_PROVIDER_MAX_INPUT_CHARS` | 4096, 512000 |
| Chat requests per minute and per day | `EZO_RATE_LIMIT_CHAT`, `EZO_RATE_LIMIT_CHAT_PER_DAY` | 10, 100 |
| Voice calls per day, concurrency, text and audio size | `EZO_VOICE_*` | 60, 1, 2000 characters, 5 MB |
| Images per request and per deck | `EZO_IMAGE_MAX_PER_REQUEST`, `EZO_IMAGE_MAX_PER_DECK` | 1, 1 |

**Mandatory before adding any key:** set a **hard monthly spend limit or budget alert in each
provider's console** (OpenAI usage limits, Google AI Studio / Cloud billing budget, Anthropic
Console limits, ElevenLabs plan). EZO's counters are not a monetary cap.

A Claude Pro or Max subscription is **not** API access. `ANTHROPIC_API_KEY` needs a separate
Anthropic Console account with its own billing.

**Durable cost ledger (design only, not implemented):**
- a `provider_usage` table with columns user, provider, model, operation, input/output
  tokens, audio seconds, characters, estimated USD (from a reviewed price table), request id
  and timestamp;
- written in the same transaction as agent-run records;
- a daily per-user and global USD ceiling checked before the call;
- an alert at 80%.

This needs its own reviewed migration and tests.

**Failure and fallback:**
- Provider order follows `models.toml`. A mid-stream failure raises an error and never
  switches providers silently mid-answer.
- With no keys, the API runs OFFLINE and says so (verified locally: "OFFLINE (no AI provider
  key found)").
- **No billable model call was made during this preparation.**

**Privacy:**
- Prompts, memories and library excerpts go to the configured provider.
- Use providers whose API terms exclude training on API data, and record each provider's
  retention.
- Explicit voice use sends audio to the voice vendor.
