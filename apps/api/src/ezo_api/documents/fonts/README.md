# Bundled fonts

`LiberationSans-Regular.ttf` and `LiberationSans-Bold.ttf` — Liberation Sans 2.1.5,
Copyright (c) 2012 Red Hat, Inc. (Reserved Font Name "Liberation"), digitized data
Copyright (c) 2010 Google Corporation (Reserved Font Arimo). Licensed under the SIL Open
Font License 1.1 (`OFL.txt`). Unmodified.

EZO uses them to measure and draw text for slide previews and PDF exports. Liberation Sans
is metric-compatible with Arial, so PPTX files EZO writes use “Arial” and the text fits the
same way in PowerPoint, Keynote and LibreOffice.
