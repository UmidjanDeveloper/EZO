# Notices — `@ezo/web`

`components/chat/AgentWeb.tsx` (the trace panel's constellation of a run's agent, route and
steps) adapts the **interface pattern** of the reasoning web in
[APEX-UI](https://github.com/RubenM1990/APEX-UI) by Ruben Mouradian (Reznikov Engineering),
MIT License (see `packages/avatar/NOTICE.md` for the licence text). What was taken: a core
with orbiting helper nodes, spokes and flowing motes that light when a helper was consulted.
What was not: no APEX-UI code, its roster of agents, palette, name or branding. EZO's web
draws only nodes the server's trace actually recorded.
